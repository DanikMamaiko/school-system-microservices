SERVICE-REGISTRY
Описание
SERVICE-REGISTRY — микросервис Eureka Server, который отвечает за сервис-дискавери и регистрацию микросервисов в распределённой системе.

Основные функции
Выполняет функции центрального реестра, в который регистрируются все микросервисы.

Отслеживает доступные инстансы каждого микросервиса.

Позволяет другим микросервисам, например, API-GATEWAY, находить зарегистрированные сервисы для взаимодействия.

Запускается на порту 8761.

Сам не регистрируется в Eureka, так как является реестром.

Принцип работы
SERVICE-REGISTRY слушает порт 8761 и хранит информацию о всех зарегистрированных сервисах, обеспечивая их обнаружение и балансировку нагрузки.

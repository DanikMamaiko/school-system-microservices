API-GATEWAY
Описание
API-GATEWAY — микросервис на базе Spring Cloud Gateway, который отвечает за маршрутизацию входящих HTTP-запросов к соответствующим бэкенд-сервисам. Он выполняет роль единой точки входа для клиентов и управляет динамической маршрутизацией с использованием сервис-дискавери через Eureka.

Основные функции
Перенаправляет запросы с путями /student/** в микросервис STUDENT-SERVICE.

Перенаправляет запросы с путями /school/** в микросервис SCHOOL-SERVICE.

Использует Eureka для обнаружения сервисов и балансировки нагрузки (URI вида lb://).

Запускается на порту 8080.

Регистрируется в Eureka-сервере.

Принцип работы
API-GATEWAY слушает порт 8080 и перенаправляет запросы согласно заданным правилам маршрутизации, используя данные сервис-дискавери из Eureka.
